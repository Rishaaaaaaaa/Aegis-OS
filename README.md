# Aegis-OS

Aegis OS is a portable, security-focused operating system designed to provide safe and private computing on untrusted or shared devices. Built on a Linux foundation, it is engineered to run directly from a USB drive, eliminating the need for installation on the host system. Aegis OS loads entirely into RAM, creating a temporary and isolated environment where all user activities are contained within the session.

Its core objective is to ensure zero-trace computing. This means that no data, cache, logs, or browsing history are written to the host machine during usage. All operations occur within the system’s memory, and any temporary data is automatically wiped once the session ends or the device is removed. For additional security, user data can be stored in encrypted form on the USB itself, ensuring protection against unauthorized access.

Aegis OS also emphasizes usability alongside security by providing a clean, customizable interface and essential system tools. It is particularly useful for students, professionals, and privacy-conscious users who frequently rely on public or shared systems. By combining portability, encryption, and RAM-based execution, Aegis OS offers a practical solution for secure, independent, and trace-free computing anywhere.
